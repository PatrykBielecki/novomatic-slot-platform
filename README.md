# Linux
Przejdź do katalogu projektu
```shell
cd slot_platform
```

Utwórz środowisko wirtualne
```shell
python3 -m venv venv
```

Aktywuj środowisko
```shell
source venv/bin/activate
```

Zainstaluj zależności
```shell
pip install -r requirements.txt
```
